質問

Noul = はい/いいえ、Choice = 2〜255 の選択肢、Score = 順序のある段階。選択肢は「id: 説明」を 1 行ずつ。 質問は互いに独立に評価され、状態は 1 回しか読まれません。

答え方:
「判断する」を押すと、ここに質問ごとの確率が出ます。

質問を増やすとどうなるか

同じ状態に対して質問数を 1 → 8 と増やし、確率方式と JSON 生成の所要時間を実測します (この場で実行)。

読み方

  • 確定 最大確率 0.85 以上。自動処理してよい帯
  • 要確認 0.5〜0.85。人が見る帯
  • 不明 0.5 未満。答えない

確率は guided choice の先頭トークンの対数確率から作っています (1 質問 1 forward、質問は並列)。 JSON 生成と「一択のみ」は確率が出ないので、棒は 0/1 になります。この画面の確率は未校正です (検証データが無いため、生の LLM は自信過剰に出ます)。実運用では検証データで温度校正してから閾値を決めます (openvons の openvons.core)。
