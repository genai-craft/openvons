# 2026-09-19 追加: JevPick の投稿案

**1/3**
```
openvons の「選ばせる」を、AIの文章生成を速くすることに使ってみました。JevPick。

次に出そうな数語の候補を並べ、モデル自身の内部状態を見て1つ選び、まとめて検算する。
ツール呼び出しで3〜5倍速。出力は1文字も変わりません。予測モデルの学習も不要。
https://openvons.com/jevpick
```

**2/3**
```
分かったこと2つ。

・ツール呼び出しは、ツール定義から機械的に作った候補の中に正解が90%入っている。選ぶ側さえ賢ければ予測モデルは要らない
・流行りの先読み手法は16kの長い文脈で速くなくなる (5.4倍→1.0倍)。効くのは「今は先読みしない」と判断する側
```

**3/3**
```
おまけ: Qwen3.5系に同梱のMTPは、ツール呼び出しで次の語を99.7%当てます。4-bitの27Bで6倍、Flash-Nextで5.8倍。エージェント用途ならONにする価値があります。

測定の全表とコードは公開しています。
https://github.com/genai-craft/openvons/tree/main/docs/jevpick
```
